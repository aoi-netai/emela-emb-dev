# emela-codegen-c-embedded

この crate は組み込み向け C バックエンドの作業用骨組みである。現時点ではファイル分割のみを用意し、コード生成、ランタイム API、CLI 統合は実装しない。

共有済みの条件と未決事項は [`docs/design/embedded-c.md`](../../docs/design/embedded-c.md) に記録する。

## 仮のモジュール境界

- `check.rs`: ターゲット機能、組み込みインターフェース、ISR 制約の検査
- `const_eval.rs`: 静的に評価できる式の評価
- `emit.rs`: C の出力
- `names.rs`: C 識別子への変換
- `runtime/`: 生成物に同梱するランタイム素材

## 実装時の考え方

- Flow IR と Heap IR の役割を分け、静的評価とターゲット検査を Heap IR 化より前に行う。
- 参照カウントを含む ISR のヒープ操作が、IR 検査をすり抜けないようにする。
- 独自実装を増やす前に既存の仕組みやライブラリを調べる。依存ライブラリの採用は、組み込み環境との適合性を確認して決める。

```text
単相化
  → Flow IR
  → 静的評価・ターゲット制約の検査
  → Heap IR
  → ISR 到達範囲のヒープ操作を再検査
  → C 出力
```
